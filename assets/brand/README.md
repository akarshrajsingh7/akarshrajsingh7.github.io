# Site icon

The favicon uses outlined Fraunces SemiBold letterforms to match the header’s `ar.` monogram, with the portfolio’s ivory background and copper dot. SVG paths avoid runtime font dependencies.

Typeface: Fraunces, distributed under the SIL Open Font License in OFL.txt.
Source: https://github.com/google/fonts/tree/main/ofl/fraunces

The PNG fallback and Apple touch icon are rendered from favicon.svg.
