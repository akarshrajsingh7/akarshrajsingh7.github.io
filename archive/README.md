# Local archive

Unused prototypes and reference files are preserved here locally and excluded from Git and the deployment build.

- `local-prototypes/`: the earlier JSON-based app (`blogs.json`, `blog.js`, related scripts/data/styles) and spare images.
- `reference-sites/philschmid.de/`: the reference website checkout, including its own Git history.

These files are not used by the live website. Their contents have not been changed. If you need to revisit the earlier blog implementation, start in `local-prototypes/`.

The tracked older portrait and logo are retained under `assets/images/legacy/`.
